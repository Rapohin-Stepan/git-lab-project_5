# Telegram-бот для поиска синонимов

Telegram-бот, позволяющий находить синонимы к словам на русском и английском языках. Бот автоматически определяет язык введённого слова и обращается к соответствующему внешнему источнику данных.

## 🎯 Назначение проекта

Проект разработан в рамках лабораторной работы. Бот выступает в роли удобного интерфейса между пользователем мессенджера Telegram и данными, предоставляемыми сторонними публичными сервисами.

## ✨ Возможности

- Автоматическое определение языка слова (кириллица / латиница)
- Поиск синонимов для **русских слов** (через парсинг сайта synonymonline.ru)
- Поиск синонимов для **английских слов** (через публичный Datamuse API)
- Обработка ошибок: неверный ввод, недоступность API, сетевые проблемы
- Информативные сообщения пользователю на всех этапах работы
- Безопасное хранение токена бота в переменных окружения

## 🛠 Используемые технологии

| Технология | Назначение |
|------------|-----------|
| Python 3.8+ | Язык программирования |
| aiogram 3.x | Асинхронный фреймворк для Telegram Bot API |
| httpx | Асинхронный HTTP-клиент для запросов к внешним API |
| beautifulsoup4 | Парсинг HTML-страниц (для русского источника) |
| python-dotenv | Загрузка переменных окружения из `.env` |

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Rapohin-Stepan/git-lab-project_5.git
cd git-lab-project_5
```

### 2. Создание виртуального окружения

Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

macOS / Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Получение токена бота

Откройте Telegram и найдите @BotFather
Отправьте команду /newbot и следуйте инструкциям
Скопируйте полученный токен вида 123456789:ABCdefGHI...

### 5. Настройка переменных окружения

Создайте в корне проекта файл .env и добавьте в него строку:
BOT_TOKEN=ваш_токен_от_BotFather

### 6. Запуск бота

```bash
python main.py
```

При успешном запуске в консоли появится сообщение:
```bash
2026-06-06 12:00:00,000 - INFO - ✅ Бот запущен и ожидает сообщения...
2026-06-06 12:00:00,001 - INFO - Start polling
2026-06-06 22:36:01,992 - INFO - Run polling for bot @user_search_synonym_bot id=... - 'synonym_bot_1'
```

## Команды бота

```bash
/start - Приветственное сообщение и запуск бота
```
```bash
/help - Справка по доступным командам
```
```bash
/synonym <слово> - Поиск синонимов к указанному слову
```

## 🛡 Безопасность

- Токен бота хранится в файле .env и не публикуется в репозитории
- Файл .env исключён из Git через .gitignore
- Логика работы с внешними API вынесена в отдельный модуль api.py
- Реализована обработка сетевых ошибок и таймаутов

## 🔗 Используемые внешние API

Datamuse API — бесплатный API для поиска английских синонимов (не требует ключа)
synonymonline.ru — онлайн-словарь русских синонимов (используется парсинг HTML)
